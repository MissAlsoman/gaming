# Thanksgiving Game Quest Mad Lib

A browser-based Thanksgiving-themed gaming Mad Lib for Gaming Concepts students.

## Use
1. Open the published GitHub Pages site.
2. Enter a word or short phrase for each prompt.
3. Select **Generate My Story**.
4. Read the story and use **Copy My Story** or **Print Story**.

No accounts, downloads, or student data collection are required. The page runs entirely in the browser.

## Publish with GitHub Pages
1. In this repository, open **Settings**.
2. Select **Pages** in the left sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Set the branch to **main** and the folder to **/(root)**.
5. Select **Save**.

When GitHub Pages finishes publishing, the site should be available at:

https://missalsoman.github.io/gaming/
